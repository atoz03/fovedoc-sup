## Memory-budget sweep — does the selector's tight-budget recall edge help the reader? (NO)

The learned selector's offline advantage is largest at **tight** memory budgets (aux-val
full-recall@8: lexical 0.669 → selector 0.941). If "better gold-block recall" mattered for
the reader, the selector should win most when the memory budget is small. It does not.

**V-MQAR, stock 2B, memory budget = top-8 blocks (n=1173, gpt-5.5 judge, 0 judge errors):**

| arm | judge | paired Δ vs naive | t | win/tie/loss |
|---|---|---|---|---|
| naive lexical memory (top-8) | 0.541 | — | — | — |
| learned selector memory (top-8) | 0.462 | **−0.079** | **−6.84** | 120/804/249 |

Combined with the top-16 main table (selector −0.056), the learned selector is **significantly
worse than naive lexical packing at both budgets**. Higher *gold-evidence recall* does **not**
translate into higher *reader-answer accuracy*: lexical ranking surfaces query-relevant,
answer-bearing text the reader actually uses, whereas the recall-optimised selector demotes it.

## Takeaways (both reader scales, n=1173, clean protocol)

1. **Headline — the retrieval–reading gap.** Retrieval is solved (full-recall@16 ≈ 1.0), yet a
   stock VLM reading the retrieved pages *as images* scores only 0.30–0.51. An explicit,
   training-free **text memory** of the *same* pages lifts it by **+0.27 to +0.33** judge
   (t ≈ 21–23, ~100 % genuine prediction-change). The bottleneck is *reading/grounding*, not
   retrieval. This holds for both Qwen3-VL-2B and -4B.
2. **Negative result — learned selection & associative layout do not help.** A distractor-robust
   selector (strong offline block-recall) and a page-grouped associative memory layout do **not**
   beat naive lexical memory: significantly worse on V-MQAR (−0.05 to −0.08 at both budgets and
   both reader sizes), neutral on V-NIAH. *Gold-evidence recall ≠ reader-answer utility.*
3. **Residual bottleneck.** V-MQAR loss decomposition (selector arm): the dominant non-correct
   bucket is reader **cross-page JOIN** failure (2B 579 / 4B 474 of ~600–730), with retrieval
   miss ≈ 0 — i.e. what remains is the reader's compositional reasoning over present evidence,
   not memory construction.
